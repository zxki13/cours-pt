# Dossier des cours

Crée un dossier par matière, puis mets tes PDF dedans :

    cours/Mathematiques/01-Reduction-des-endomorphismes.pdf
    cours/Physique-Chimie/Thermodynamique/02-Premier-principe.pdf
    cours/Sciences-Industrielles/03-Cinematique-du-solide.pdf

- Un sous-dossier dans une matière devient un chapitre sur le site.
- Les chiffres au début du nom servent à trier (ils ne s'affichent pas).
- Évite les accents dans les noms de dossiers (le site les ajoute tout seul pour les matières courantes).
